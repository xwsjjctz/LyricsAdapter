# LyricsAdapter

**一款以本地音乐和同步歌词为核心的桌面播放器。**

听本地收藏，连接 WebDAV 云曲库，也可以通过插件接入 QQ 音乐与网易云音乐。

[下载安装](https://github.com/xwsjjctz/LyricsAdapter/releases) · [English](README.en.md)

## 开始使用

从 [Releases](https://github.com/xwsjjctz/LyricsAdapter/releases) 下载适合设备的安装包。当前发布配置提供 macOS Apple Silicon 的 `.dmg` 和 Windows x64 的 `.exe` 安装包。

> **Windows 首次安装提示**：安装包暂未进行代码签名，运行时 Microsoft Defender SmartScreen 可能会显示「Windows 已保护你的电脑」，发布者为「未知发布者」。确认安装包来自本仓库的 Releases 后，点击「更多信息」，再点击「仍要运行」即可继续安装。
>
> **macOS 首次打开提示**：应用暂未进行 Apple 公证，首次打开时 macOS 可能提示无法验证开发者。将应用拖入「应用程序」文件夹并尝试打开一次后，前往「系统设置 → 隐私与安全性」，在页面下方点击「仍要打开」并确认。如果提示应用「已损坏，无法打开」，请在终端运行 `xattr -dr com.apple.quarantine /Applications/LyricsAdapter.app` 后重新打开。

1. 打开应用，按 `⌘ / Ctrl` + `I` 选择 **MP3 或 FLAC** 文件，或者直接把音频文件拖进窗口。曲库为空时，也可以点击中间的「导入文件」。
2. 点击封面开始播放，用底部的悬浮播放栏控制播放。
3. 点击专注模式按钮，或按 `⌘ / Ctrl` + `Enter`，查看同步歌词。macOS 上这个按钮是窗口左上角红绿灯旁的蓝色圆点，Windows 上在标题栏右侧。

本地音乐无需登录即可使用。导入时会读取文件中的标题、艺术家、专辑、封面和内嵌歌词。

## 曲库与播放

### 海报墙

曲库默认以海报墙展示：封面按窗口宽度自动排版，大小交错；窗口变窄时会改用更紧凑的排版。正在播放的封面会随音乐律动发光，切歌后海报墙会自动滚动到当前歌曲。

喜欢传统列表的话，可以在命令面板的「功能」中选择「切换到旧版列表」，再次选择「切换到瀑布流」即可切回。

![旧版列表](docs/images/list.webp)

### 竖屏

把窗口调成竖长形状即可使用竖屏布局；macOS 也可以在菜单栏选择「窗口 → 竖屏」，一键切换到 385 × 800 的窄窗口，选择「横屏」恢复。竖屏时海报墙改用紧凑排版，专注模式把封面和歌曲信息移到顶部，歌词占满下方，播放控制在操作时才出现。

### 播放控制

底部悬浮播放栏提供播放／暂停、上一首／下一首、进度调节、音量和静音控制，支持顺序播放、随机播放和单曲循环。

应用会记住当前曲库、曲目、播放进度和音量等状态，重新打开后从暂停状态恢复。浏览其他曲库或打开歌单时，可以继续收听当前歌曲。

### 命令面板

按 `⌘ / Ctrl` + `K` 打开命令面板，按 `Tab` 在「音乐库」和「功能」两种模式之间切换。

- **音乐库**：搜索歌曲、歌手、专辑或歌单，同时查找本地与已加载的云端曲目，支持中文拼音和拼音首字母。启用音乐源插件后，结果中还会显示在线歌曲：点击即可播放，点击右侧的 `+` 加入在线播放记录，右键可选择音质下载。
- **功能**：切换曲库、打开或管理歌单、导入文件、批量选择、刷新云端曲库、播放全部、随机播放、定位到当前播放、切换外观与语言、打开设置的各个页面等。

![命令面板：搜索](docs/images/palette.webp)

![命令面板：功能](docs/images/commands.webp)

### 切换曲库与歌单

应用把「本地」「云端」「在线播放记录」和已登录平台的歌单都当作可切换的曲库。可以在命令面板中选择，也可以使用歌单切换器：按住 `⌘ / Ctrl`，连续按数字 `1` 左侧的按键（`` ` ``）在曲库和歌单之间循环，松开 `⌘ / Ctrl` 确认；同时按住 `Shift` 反向切换，按 `Esc` 取消。

### 整理本地曲库

在封面上点右键（或按键盘上的菜单键），可以：

- **编辑歌曲信息**：修改标题、艺术家、专辑、歌词，或导入新封面。仅本地曲目可用，保存后写回音频文件。
- **选择多首歌曲**：进入批量选择，底部会出现全选、移除所选和完成按钮。
- **从曲库移除**：只把歌曲移出曲库，原音频文件会保留。

在「本地」和「在线播放记录」中，可以拖动封面调整顺序。

## 歌词与专注模式

专注模式展示专辑封面、随封面变化的背景和滚动歌词，保留常用播放控制。点击带时间信息的歌词，可以跳转到对应位置播放。

![专注模式](docs/images/focus.webp)

- **逐行歌词**：读取音频内嵌的 LRC 歌词，随播放进度滚动。
- **逐字歌词**：歌曲提供 QRC／YRC 等逐字时间信息时，显示逐字高亮。
- **显示调整**：在「设置 → 专注模式」中开启 Apple Music 风格的「动态流光背景」，或调节背景不透明度、背景模糊、歌词字号和行间距。Windows 还提供「新版 FocusMode 字体」开关。

没有歌词时会显示相应提示。可以在本地曲目的「编辑歌曲信息」中补充歌词；同步滚动需要歌词包含时间标签。

![专注模式设置](docs/images/settings.webp)

### 系统歌词与媒体控制

| 平台 | 系统歌词 |
| --- | --- |
| macOS | 在菜单栏显示当前歌词，并提供上一首、播放／暂停、下一首控制。 |
| Windows | 在任务栏显示歌词，支持逐字高亮和悬停播放控制。 |

播放信息也会提供给系统媒体控制，便于查看歌曲信息和控制播放。

## WebDAV 云曲库

按 `⌘ / Ctrl` + `,` 打开设置，在「云端曲库」中填写服务器地址、账号和应用密码，测试连接后保存。然后在命令面板中选择「切换到云端」。

- 加载服务器上的音乐，以海报墙或列表浏览并在线播放。
- 在命令面板的「功能」中选择「刷新云端曲库」，更新云端曲库。
- 在命令面板中搜索已加载的云端歌曲。

云端播放需要可用的网络连接。本地文件和在线歌曲上传到 WebDAV 的入口目前已停用；已有云端曲库读取、播放、刷新和元数据缓存机制保持不变。

## 在线音乐与歌单

### 安装音乐源插件

QQ 与网易云接口实现独立维护在 [LyricsAdapter-Music-Plugins](https://github.com/xwsjjctz/LyricsAdapter-Music-Plugins)。主应用可无插件启动：

1. 打开「设置 → 插件」，在「官方插件」中下载安装 QQ 音乐或网易云音乐插件，也可以通过「安装本地插件」导入 `.laplugin` 文件。
2. 启用插件后即可在命令面板中搜索在线歌曲，登录在该插件卡片的「设置」中完成。

首次安装立即生效，更新已有插件后需要重启应用。每个插件运行在独立进程中；安装或更新第三方来源的插件前，应用会请你确认来源。禁用插件后会保留歌曲、歌单与登录数据。

安装文件集中保存在 `~/.la/plugin/<插件 ID>/`，插件页会显示实际路径并提供打开文件夹的入口。第三方开发者可阅读[插件 API 文档](docs/plugins/README.md)，使用通用接口注册音乐源或歌词翻译能力；任何音乐源插件都可以按 manifest 接入在线音乐界面。启用翻译插件后，专注模式会出现「翻译」按钮，提供对照译文。开发合同与构建说明见[音乐源插件文档](docs/music-source-plugins.md)。

### 登录

在「设置 → 插件」中展开对应音乐源插件的「设置」，使用该平台的手机应用扫码并确认登录，也可以手动填写 Cookie 后点「验证并保存」。插件卡片上会显示是否已登录。

QQ 音乐需要有效的登录凭证才能参与在线搜索；网易云音乐支持匿名搜索和试听。个人歌单需要登录对应平台，歌曲能否播放、下载以及可用音质取决于平台返回的资源和账号权限。

### 搜索、试听与下载

在命令面板的「音乐库」模式中输入关键词，在线结果会标明 QQ 或网易来源。点击歌曲即可试听，试听过的歌曲会出现在「在线播放记录」中。

下载前，在「设置 → 通用」中选择保存文件夹，也可以输入 `~/Music` 这样的路径。在命令面板的在线结果上，或在「在线播放记录」和歌单的封面上点右键，选择音质下载：

| 音质 | 选项 |
| --- | --- |
| 标准 | 128 kbps |
| 高品质 | 320 kbps |
| 无损 | FLAC |

下载进度会显示在封面上。下载完成的歌曲会加入本地曲库，并写入可获取的歌曲信息、封面和歌词。

### 浏览歌单

登录后，命令面板的「音乐库」模式会列出对应平台的歌单，也可以在「功能」中选择「打开歌单」，或用歌单切换器切换。较长的歌单会在向下滚动时继续加载。

在「功能」中选择「管理歌单显示」，可以隐藏或重新显示歌单。此操作只影响应用中的显示，不会删除平台上的歌单。

## 外观与快捷键

在命令面板的「功能」中选择「黑白切换」，可以在深色和浅色外观之间切换。

设置的「通用」页提供中文、英语、日语、韩语、德语和法语界面，也可以检查应用更新。

常用默认快捷键如下，macOS 使用 `⌘`，Windows 使用 `Ctrl`：

| 操作 | 快捷键 |
| --- | --- |
| 播放／暂停 | `Space` |
| 上一首／下一首 | `⌘ / Ctrl` + `← / →` |
| 后退／前进 5 秒 | `← / →` |
| 后退／前进 30 秒 | `Alt` + `← / →` |
| 降低／提高音量 | `↓ / ↑` |
| 降低／提高音量 10% | `Alt` + `↓ / ↑` |
| 静音／取消静音 | `M` |
| 切换播放模式 | `Tab` |
| 进入／退出专注模式 | `⌘ / Ctrl` + `Enter` |
| 命令面板 | `⌘ / Ctrl` + `K` |
| 切换歌单 | `⌘ / Ctrl` + `` ` `` |
| 搜索音乐 | `⌘ / Ctrl` + `F` |
| 导入文件 | `⌘ / Ctrl` + `I` |
| 打开设置 | `⌘ / Ctrl` + `,` |

在「设置 → 快捷键」中点击按键组合即可重新绑定，按 `Esc` 取消，按 `Backspace` 或 `Delete` 清除绑定，也可以恢复默认设置。

## 开发

使用 Node 24.19.0 或更新的 24 系列版本。主应用可在无插件、无插件源码时启动：

```sh
npm ci
npm run electron:dev
```

`npm run check` 会检查、测试和构建主应用。插件开发和独立验证见 [音乐源插件文档](docs/music-source-plugins.md)。调试和隔离数据说明见 [DEBUGGING.md](DEBUGGING.md)。
